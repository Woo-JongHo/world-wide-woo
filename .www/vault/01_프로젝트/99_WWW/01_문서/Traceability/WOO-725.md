# 목적

Layout 극단 크기·anchor 실패·동적 내용·overlay 종료 예외에서 화면과 입력을 복구하는 계약을 기록한다.

# 배경과 결정

예외 처리의 목표는 원래 위치를 완벽히 추측하는 것이 아니라 잘못된 패널로 이동하지 않고 지원되는 fallback과 입력 복귀를 제공하는 것이다.

2026-09-07 초안 당시 `createDashboardLayout`의 Code-013 등록은 미완료였다. 현재 `src/tui/layout/dashboard-layout.ts`의 이름 있는 최상위 function `createDashboardLayout`에 ` Code-013`이 선언되어 있고, 같은 파일의 `ChatScrollView`는 기존 Code-003 identity를 유지한다.

스냅샷 기준 상태는 `Backlog`, parent는 `WOO-680`이며 제목과 보호 메타데이터는 변경하지 않는다.

# 상세 동작

ChatScrollView는 anchor 문자열을 길이 80으로 저장하고 16자까지 단계적으로 검색한 뒤, 찾지 못하면 content fraction을 사용한다. fit/truncateToWidth는 각 행을 viewport에 맞추며 visible predicate가 88열·14행 경계를 처리한다.

# 예외

anchor 삭제·중복, 0폭, 높이 경계 진동, Unicode 폭, overlay focus target 소멸, dynamic tail 변경을 다룬다. overlay close는 승인 결정으로 바뀌지 않는다.

# 테스트 방법

40·87·88열, 13·14행, anchor 삭제/중복, dynamic tail, 한글·emoji, overlay 비정상 종료 fixture를 추가하고 실제 TUI 복구를 조작한다.

# 실제 결과

폭 제한, 낮은 높이 접근, dynamic tail, contained scroll 테스트가 통과했다. anchor 실패와 경계 진동, overlay 종료의 실제 복구를 직접 다루는 증거는 부족하다.

# 남은 항목

예외 전용 자동 테스트와 실제 화면 근거, 안전한 focus fallback, Code-003→Code-013 원장 정합화를 완료해야 한다.
