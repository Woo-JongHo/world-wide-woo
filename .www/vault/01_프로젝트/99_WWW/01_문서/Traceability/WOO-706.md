# 목적

선택한 Source의 공개 내용과 관측 한계·참조 metadata를 구분해 읽는 요구를 기록한다.

# 배경과 결정

보존된 공개 projection만 표시하고 provider 원본 전체나 숨겨진 reasoning으로 확대하지 않는다. Chat의 가독성 표현을 재사용하되 Source는 원본 수정 기능이 아니다.

2026-09-07 초안 당시 `DevelopmentService`는 Code-012 등록 전 후보였다. 현재 `src/workflows/tui-development/service.ts`의 이름 있는 최상위 class `DevelopmentService`에 ` Code-012`가 선언되어 있고, frontmatter UUID와 traceability-v2 원장이 일치한다.

스냅샷 기준 상태는 `Todo`, parent는 `WOO-681`이며 제목과 보호 메타데이터는 변경하지 않는다.

# 상세 동작

selectedSourceRows는 selectedActivityId를 journal에서 찾고 `boundedPublicProjection`으로 payload를 정제한다. JSON 표시, omission 경고, thread·turn·item refs와 Source 상태를 별도 행으로 만든다. 선택 없음과 원본 부재는 서로 다른 문구를 사용한다.

# 예외

긴 payload, 제어문자·ANSI, 민감 표식은 제한·정제해야 한다. partial resume에서 없는 원본은 normal empty source가 아니며 다른 activity로 대체하지 않는다.

# 테스트 방법

workbench view의 selected/unavailable/partial Source 사례와 폭 테스트에 긴 코드·한글·비정상 ANSI·민감값 fixture를 추가한다. 40·80·120열 실제 Source 화면을 기록한다.

# 실제 결과

bounded projection과 선택 없음/원본 부재 구분이 코드에 있으며 관련 view·delegation 테스트가 통과했다. 사람이 읽는 본문과 metadata 위계, 실제 Native TUI 탐색 수락은 아직 완전한 근거가 없다.

# 남은 항목

긴 payload 생략 단위, partial coverage 표시, Chat과의 문서 렌더 일관성, 실제 Source 왕복과 Code-012 등록이 남아 있다.
