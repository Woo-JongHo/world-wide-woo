# 목적

선택한 Plan과 결과에서 같은 실행의 공개 구조와 Source를 찾고 원래 맥락으로 돌아오는 Tracer 통합 요구를 기록한다.

# 배경과 결정

Tracer는 exact activity identity와 Plan association을 구분한다. 직접 관측한 thread·turn·item은 observed이고 Plan 귀속은 현행 dplan projection에서 inferred일 수 있다. 비공개 reasoning·민감값과 승인 결정은 범위 밖이다.

2026-09-07 초안 당시 `DevelopmentService`는 Code-012 등록 전 후보였다. 현재 `src/workflows/tui-development/service.ts`의 이름 있는 최상위 class `DevelopmentService`에 ` Code-012`가 선언되어 있고, frontmatter UUID와 traceability-v2 원장이 일치한다.

스냅샷 기준 상태는 `In Progress`, parent는 `WOO-674`이며 제목과 보호 메타데이터는 변경하지 않는다.

# 상세 동작

`resolveActivitySelection`은 exact activity ID, 중복, 현재 thread를 검증한다. `resolveTraceSelection`은 Plan source, turn/item ref, 단일 Plan membership을 추가 확인하고 구조화된 실패와 coverage를 반환한다. `WorkbenchMonitorView`는 Plan·Trace와 bounded Source를 표시한다. `DevelopmentService`는 선택한 개발 작업에 귀속된 공개 activity capture와 turn 완료 시점의 frozen checkpoint를 담당하는 대표 후보다.

# 예외

동일 itemId가 다른 turn에 재사용되거나 journal이 resume 이후 일부만 있으면 latest activity로 대체하지 않는다. 원본 부재·모호한 Plan 연관·oversize payload는 각각 실패 또는 제한 상태로 남긴다.
