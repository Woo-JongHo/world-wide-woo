# 0001 · Chat 표시

Code-ID는 기능을 찾는 짧은 식별자다. 파일 경로·함수·Linear 이슈가 바뀌어도 기능의 동일성이 유지되면 번호를 유지한다. 기존 Unit UUID를 이 번호로 교체하지 않는다.

## 코드 위치

`src/presentation/tui/workbench-views.ts`의 `WorkbenchChatView`에 `@codeId 0001`이 선언돼 있다.

- `update`: 완료 본문의 Markdown 캐시와 공개 draft 투영을 갱신한다. live draft는 크기를 제한하고 완료 본문과 구분한다.
- `renderMessage`: 역할·상태·본문을 표시하고 Markdown 렌더 실패를 메시지 단위로 격리한다.
- 실행 카드: thread/turn/item을 구분하고 정확한 activity의 Source 링크를 표시한다.

## 요구 및 구현

[WOO-679](https://linear.app/woo-world/issue/WOO-679)와 기능 하위 이슈를 참조한다. [PR #46](https://github.com/Woo-JongHo/world-wide-woo/pull/46)에 구현·테스트·Opus 감사 원문이 있다.

## 검증

`test/chat-render-acceptance.test.ts`, `test/workbench-views.test.ts`에서 폭·본문·역할·상태·오류 격리를 검증한다. 전체 방법론·기대값·실패 유형·실측 한계는 [Chat 검증 기록](2026-09-07-Chat-Completion-Verification.md)에 둔다.

## 연결 상태

등록 원장은 `.www/control-ledger/code-ids.json`이다. 코드 선언·Linear·문서의 파일럿 연결이며, 기존 SQLite Unit UUID와 Code-ID를 연결하는 조회·등록 기능은 아직 구현하지 않았다. SQLite 연결이 끝났다고 해석하지 않는다.

현재 연결 이슈 목록은 `.www/control-ledger/code-ids.json`이 소유한다. 노트에 그 목록을 중복 보관하지 않는다.
