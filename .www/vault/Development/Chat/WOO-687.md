# WOO-687 · 02. 대화 주체와 진행 상태를 한눈에 구분한다

Linear 본문을 얇게 정리하기 전의 상세 요구·기록을 보존한다. 상태는 기록 시점의 것이며 최신 구현은 [PR #46](https://github.com/Woo-JongHo/world-wide-woo/pull/46)과 [[2026-09-07-Chat-Completion-Verification]]에서 확인한다.

## 결과

대화의 내용에 집중하면서도 누가 보낸 말인지, 응답이 진행 중인지 끝났는지 혼동하지 않는다.

## 범위

### 기능과 화면 기준

| 대상 | 표시 원칙 |
| -- | -- |
| 사용자 | 역할 label과 낮은 대비의 배경으로 입력 경계 표시 |
| Agent | 역할 label, 열린 본문 배경, 일관된 문단 간격 |
| 응답 중 | 본문 가까이에 짧은 진행 문구 |
| 실패·중단 | 상태명·기호와 남은 본문, 가능한 다음 행동 |
| 전송 대기·수신 불확실 | 완료된 발화와 구분되는 안내 |
| 운영 알림 | 발화로 꾸미지 않고 Chat 알림 영역에 표시 |

* 기존 `semantic.userLabel / assistantLabel / userSurface / noticeSurface / tool*` token을 사용한다.
* 매 메시지에 시간·내부 ID·중복 상태를 상시 늘어놓지 않는다.
* 무채색에서도 label·배치·문구로 역할과 상태를 구별한다.
* 알 수 없는 역할·상태를 정상 Agent 답변이나 성공으로 추정하지 않는다. 오류 fallback은 [WOO-691](https://linear.app/woo-world/issue/WOO-691/message-예외처리)과 연결한다.

## 완료 조건

- [ ] 사용자·Agent·전송 대기·운영 오류가 연속되어도 발화 경계를 구분한다.
- [ ] streaming·completed·failed·cancelled를 색 없이 판별한다.
- [ ] 좁은 폭에서 label과 상태가 본문과 겹치지 않는다.
- [ ] 정상·실패·중단 화면의 같은 상태에 같은 문구와 위계를 사용한다.

검증 시작점: `test/workbench-views.test.ts`. 상태 전이 자체는 [WOO-688](https://linear.app/woo-world/issue/WOO-688/message-03-답변-생성완료중단-과정을-보여준다), 재개 identity는 [WOO-690](https://linear.app/woo-world/issue/WOO-690/message-05-재개-뒤에도-대화-순서와-대상을-유지한다)에서 검증한다.
