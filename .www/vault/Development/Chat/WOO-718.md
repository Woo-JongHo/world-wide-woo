# WOO-718 · 08. 대화·실행·결과를 하나의 흐름으로 연결한다

Linear 본문을 얇게 정리하기 전의 상세 요구·기록을 보존한다. 상태는 기록 시점의 것이며 최신 구현은 [PR #46](https://github.com/Woo-JongHo/world-wide-woo/pull/46)과 [[2026-09-07-Chat-Completion-Verification]]에서 확인한다.

## 결과

Chat 01~08의 내용을 대화·실행·결과 흐름으로 연결해 한 요청의 전체 맥락을 잃지 않게 한다.

## 범위

Chat에서 이 번호 항목의 결과를 구현한다. 예외 처리 기록은 [WOO-719](https://linear.app/woo-world/issue/WOO-719/예외-처리), 테스트 기록은 [WOO-720](https://linear.app/woo-world/issue/WOO-720/테스트)에 연결한다.

## 완료 조건

- [ ] 사용자 발화, Agent 답변, 실행 카드, 상태, 결과 요약이 한 흐름으로 읽힌다.
- [ ] 같은 요청의 갱신은 중복 카드로 쌓이지 않는다.
- [ ] 다른 thread·turn·item의 내용이 섞이지 않는다.
- [ ] 실제 TUI의 40·80·120열에서 순서와 상태를 확인한다.

## 코드 연결

src/presentation/tui/workbench-views.ts — 대화·실행·결과 projection; src/application/project-workbench.ts — Native 관측과 요청 identity. 코드 존재만으로 수락 완료를 뜻하지 않는다.

## 검증

[WOO-720 테스트](<https://linear.app/woo-world/issue/WOO-720>)에서 종류·유형·기대값·실제 결과·실패와 원본 증거를 확인한다. 현재 Chat 통합 브랜치에서 구현·회귀·실제 재개 검증을 진행 중이며 전체 수락은 미완료다.
