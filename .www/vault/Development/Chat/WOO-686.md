# WOO-686 · 01. 문서와 코드를 읽기 쉽게 표시한다

Linear 본문을 얇게 정리하기 전의 상세 요구·기록을 보존한다. 상태는 기록 시점의 것이며 최신 구현은 [PR #46](https://github.com/Woo-JongHo/world-wide-woo/pull/46)과 [[2026-09-07-Chat-Completion-Verification]]에서 확인한다.

## 결과

긴 답변에서도 제목, 설명, 목록, 코드의 경계를 빠르게 찾고 필요한 내용을 편하게 읽는다.

## 범위

### 기능과 화면 기준

* 제목은 단계와 강조를 구분하고 문단·목록·인용에는 일정한 여백과 들여쓰기를 준다.
* inline Code와 fenced Code를 본문에서 분리한다. 언어가 확인되면 문법색을 적용하고 미지원 언어·강조 실패는 읽을 수 있는 plain 표시로 돌아간다.
* 링크는 label과 목적지를 구분하여 표시한다. 긴 URL·파일 경로가 줄 폭을 넘거나 다음 문단을 밀어내지 않도록 한다.
* Markdown 표는 셀 내용과 헤더 관계를 유지해 표시한다. 현재 사용하는 pi-tui 0.84.4의 Markdown renderer에 표 줄바꿈과 좁은 폭의 raw Markdown fallback이 있으므로, 이를 실제 Chat에서 읽기 좋게 적용·검증한다.
* 완료된 답변은 공개용 정제 후 전체 내용을 보존한다. 스트리밍 draft의 제한과 완료 본문의 표시 정책을 혼동하지 않는다.
* ANSI 입력의 제어 효과는 제거하고 WWW theme의 강조를 적용한다. 미완성 fence도 해당 메시지 안에서 읽을 수 있게 표시한다. 메시지 간 오류 전파 차단은 [WOO-691](https://linear.app/woo-world/issue/WOO-691/message-06-비정상-응답에서도-내용을-보존하고-복구를-안내한다)에서 확인한다.

## 완료 조건

- [ ] 제목·중첩 목록·인용·링크·표·inline Code·fence가 섞인 한 답변에서 구조와 원래 순서를 보존한다.
- [ ] TypeScript·JSON·Bash·언어 없는 fence·미지원 언어·미완성 fence를 40·80·120열로 확인한다.
- [ ] 문법 강조 실패·budget 초과에서도 본문이 사라지거나 TUI가 종료되지 않는다.
- [ ] 완료 본문의 앞·중간·끝을 확인하고 생략이 있는 경우 그 이유와 확인 경로를 표시한다.

검증 시작점: `test/workbench-views.test.ts`, `test/syntax-highlighter.test.ts`. `test/transcript-markdown.test.ts`는 legacy TranscriptView 테스트이므로 Native Workbench 수락 근거로 단독 사용하지 않는다.

## 코드 연결

* [src/presentation/tui/workbench-views.ts](<https://github.com/Woo-JongHo/world-wide-woo/blob/main/src/presentation/tui/workbench-views.ts>) — update / renderMessage: 완료 본문 Markdown, draft에 boundedWorkbenchMarkdown 적용
* [src/presentation/tui/theme.ts](<https://github.com/Woo-JongHo/world-wide-woo/blob/main/src/presentation/tui/theme.ts>) — markdownTheme: heading·link·code·quote·list·highlightCode
* [src/presentation/tui/syntax-highlighter.ts](<https://github.com/Woo-JongHo/world-wide-woo/blob/main/src/presentation/tui/syntax-highlighter.ts>) — createNativeSyntaxHighlightPlugin: native highlight와 budget/실패 fallback
* [src/domain/terminal.ts](<https://github.com/Woo-JongHo/world-wide-woo/blob/main/src/domain/terminal.ts>) — sanitizeTerminalTextUnbounded: 제어문자 제거·공개용 정제

이미 Markdown·문법 강조를 사용한다. 강조 budget은 200,000 bytes / 2,000 lines이며 초과 시 plain으로 표시하는 코드가 있다. 모든 완료 메시지를 120행으로 자른다는 과거 설명은 현행 코드와 다르다. 2026-09-06의 `99_www` 작업 트리(미커밋 변경 포함)를 읽은 기준이다. 코드 링크는 `main` 탐색용이며 로컬 변경의 배포·수락을 뜻하지 않는다. 아래 완료 기준은 앞으로 확인할 항목이다.
