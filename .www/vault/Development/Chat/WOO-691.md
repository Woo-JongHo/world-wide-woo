# WOO-691 · 06. 비정상 응답에서도 내용을 보존하고 복구를 안내한다

Linear 본문을 얇게 정리하기 전의 상세 요구·기록을 보존한다. 상태는 기록 시점의 것이며 최신 구현은 [PR #46](https://github.com/Woo-JongHo/world-wide-woo/pull/46)과 [[2026-09-07-Chat-Completion-Verification]]에서 확인한다.

## 결과

응답이 비어 있거나 형식·연결에 문제가 생겨도 대화 화면이 무너지지 않고, 사용자가 현재 상태와 다음 행동을 이해한다.

## 범위

### 예외별 동작

| 상황 | 기대하는 표시·행동 |
| -- | -- |
| 빈 본문으로 종료 | 실제 종료 상태를 표시하고 답변 본문이 없음을 알림 |
| 미완성 Markdown·fence | 읽을 수 있는 text를 남기고 다음 메시지에 스타일이 번지지 않음 |
| 언어 미지원·강조 실패 | plain text로 표시, 전체 응답 렌더 실패로 확대하지 않음 |
| 제어문자·비정상 ANSI | terminal 조작 효과를 제거한 안전한 텍스트 표시 |
| 비정상 role/status/payload | 해당 항목의 확인 불가 알림, 정상 답변·성공으로 추정하지 않음 |
| 연결 끊김·수신 불확실 | 이미 읽은 본문을 유지하고 현재 가능한 확인 동작 안내 |
| 일부 메시지 표시 실패 | 실패 범위를 해당 항목으로 제한하고 나머지 대화·입력 기능 유지 |

### 책임과 복구 원칙

* Message 본문·상태·순서의 정상 흐름은 상위 기능 [Chat WOO-679](<https://linear.app/woo-world/issue/WOO-679>)이 소유한다.
* 이 이슈는 빈 응답, 비정상 payload, 정제 실패, 연결 불확실성과 항목별 복구 안내를 소유한다.
* 오류는 본문과 구분되는 짧은 notice로 표현하고, 원시 stack·payload는 대화에 펼치지 않는다.
* 재시도·확인·취소는 실제 가능한 행동만 표시한다. 원본·공개용 정제·화면 생략을 구분한다.

## 완료 조건

- [ ] 표의 예외마다 입력 fixture와 기대 화면·복구 동작을 남긴다.
- [ ] 오류 이후 정상 메시지를 받거나 다음 입력을 처리해 화면이 복구되는지 확인한다.
- [ ] 실패 전에 읽은 부분 답변을 보존하고 미수신 내용을 만들어 넣지 않는다.
- [ ] 원시 제어문자·민감값이 공개 오류 표시로 새어 나오지 않는다.
- [ ] 불가능한 재시도·취소 안내가 없으며 오류를 성공으로 표시하지 않는다.

검증 시작점: `test/workbench-views.test.ts`, `test/project-workbench.test.ts`, `test/syntax-highlighter.test.ts`.
