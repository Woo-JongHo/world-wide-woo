# 0003 · Chat 읽던 위치

코드 위치: `src/presentation/tui/dashboard-layout.ts`의 `ChatScrollView`. 선언 `@codeId 0003`와 `.www/control-ledger/code-ids.json`으로 연결한다.

[PR #46](https://github.com/Woo-JongHo/world-wide-woo/pull/46)에서 구현과 감사를 확인한다. 상세 요구는 [[WOO-679]], 테스트 방법론·실제 결과·한계는 [[2026-09-07-Chat-Completion-Verification]]에 있다.

현재 연결 이슈 목록은 `.www/control-ledger/code-ids.json`이 소유한다. 노트에 그 목록을 중복 보관하지 않는다.
