# WWW 문서 지도

현재 제품 목적은 [WWW 제품 방향](WWW_PRODUCT_DIRECTION.md)이 소유한다. [기존 도구와의 경계](OSS_POSITIONING.md)는 GJC·Pi·OMO·OMX와의 관계를 설명한다. 설치와 현재 구현 상태는 [루트 README](../README.md)를 따른다.

그 밖의 문서는 이전 제품 방향을 검토하면서 남긴 연구·설계·감사·개발 기록이다. 특히 `docs/planning/`, `docs/workflows/`, `docs/audit/`, `docs/research/`의 단계형 Workflow와 WOO 기록 절차는 현재 WWW 사용자 계약이 아니다. 해당 기록을 제품 기능으로 해석하거나 공개 설치 절차에 포함하지 않는다.

공개 패키지를 만들 때에는 제품 사용에 필요한 문서만 포함하고, 과거 기록과 WOO 개발 스킬·훅·증거는 배포 대상에서 제외한다. 실제 패키지 구성이 바뀌기 전까지 배포 경량화가 완료됐다고 표시하지 않는다.
