# WOO-695 · Unit과 Linear 연결

## 목적

사람이 읽는 Code-NNN과 내부 Unit UUID를 일대일 별칭으로 연결한다.

## 배경과 결정

schema v2 원장이 UUID, key, lifecycle, aliases, locations와 Linear edge를 소유한다. Code-000은 예시이며 발급하지 않는다.

Linear에는 목적·결과·범위·동작·완료 조건과 연결만 둔다. Code-ID는 평문 `Code-006`이며 대표 선언의 `@Unit Code-006`로 찾는다.

## 상세 동작

원장의 Issue UUID, Unit UUID, Vault 상대 경로를 함께 검증한다. SQLite는 동일 원장의 digest로 재구축하며, Development Map은 그 투영을 사람이 읽는 표로 생성한다.

## 예외

ID 중복·별칭 재사용·끊어진 edge·stale 코드 위치·잘못된 frontmatter·오래된 SQLite·Map diff는 정상 결과로 숨기지 않고 gate 실패로 반환한다.

## 테스트 방법

`bun run traceability:check`로 원장, AST, Obsidian, SQLite rebuild, Map freshness를 한 번에 확인한다. mutation fixture에서 각 연결을 하나씩 끊어 gate가 실패하는지도 확인한다.

## 실제 결과

검증 결과와 명령 출력은 `.www/evidence/v020-traceability/verification.json` 및 같은 디렉터리의 로그에 기록한다.

## 남은 항목

Linear 외부 UI 편집은 차단하지 않는다. 반영 전 draft gate와 반영 후 MCP readback gate로 감지한다.
