# 목적

Plan 항목에 결속된 모델·agent의 담당 작업과 상태를 Todo에서 확인하는 요구를 기록한다.

# 배경과 결정

Todo에는 입력과 Plan에 관련된 ‘누가 무엇을 하는가’만 둔다. 전체 실행·승인은 Monitor, node Source는 Tracer로 넘긴다. 설정 모델을 실제 모델로 추정하지 않는다.

대표 후보는 `src/application/todo-ledger.ts`의 이름 있는 최상위 class `TodoLedger`다. 현재 선언과 traceability-v2 원장에는 Code-011이 아직 없으며, 이 UUID는 향후 원장 등록을 위한 초안 값이다.

스냅샷 기준 상태는 `Todo`, parent는 `WOO-682`이며 제목과 보호 메타데이터는 변경하지 않는다.

# 상세 동작

TodoDocument source와 item source에는 provider/model/agentId/threadId/runId 참조가 있다. WorkspaceTodoView는 root execution과 `projectNativeDelegation` 결과를 같은 turn 및 step activityIds로 대조해 결속된 task를 항목 아래 표시하고, 남은 task는 ‘실행 연결 미확정’으로 표시한다.

# 예외

동일 모델의 여러 agent를 합치거나 다른 세션 activity를 붙이면 안 된다. model/agent가 관측되지 않은 resume은 미확인/null로 유지하며 terminal state가 Plan 완료나 업무 수락을 바꾸지 않는다.

# 테스트 방법

두 세션의 서로 다른 model reference, resume 시 미관측 model/agent null, delegation turn 격리와 상태 전환 테스트를 사용한다. 병렬 두 모델·동일 모델 다중 agent·실패/중단의 실제 run을 추가한다.

# 실제 결과

세션별 model/run 참조와 observed delegation 표시, 미결속 count가 코드에 있다. 관련 자동 테스트는 대부분 통과하지만 실제 다중 모델 Native 실행을 통한 Plan-item 결속 수락 근거는 확인되지 않았다.

# 남은 항목

실제 병렬 모델·agent 실행, 동일 모델 다중 agent 격리, stale/끊김 표시, Plan 결속 불변식의 전용 테스트와 Code-011 등록이 남아 있다.
