# World Wide Woo

WWW는 여러 AI 모델에 맡긴 작업을 한 터미널에서 실행하고 관찰하는 도구를 목표로 한다. 사용자가 주 모델을 선택하고, 연결된 다른 모델은 요청할 때 검토에 사용하도록 설계한다. 실패 시 다른 모델로 전환한다면 이유와 실제 응답 모델을 보여주는 것이 제품 계약이다.

## 화면의 의미

```text
대화: UNDERSTAND → WORK → RESULT
옆 패널: PLAN · PROGRESS · TEST
```

- **UNDERSTAND**: 사용자의 요청을 어떻게 이해했는지 표시한다.
- **WORK**: 실행 중인 도구와 관찰 가능한 활동을 표시한다.
- **RESULT**: 산출물, 확인한 내용, 남은 문제를 표시한다.
- **PLAN · PROGRESS · TEST**: 필요한 경우에만 계획, 진행, 검증 상태를 보여준다.

이 표시는 작업을 일곱 단계로 강제하지 않는다. 간단한 질문에는 간단하게 답할 수 있어야 한다. 모델의 비공개 추론을 보여준다고 주장하지 않는다.

## 현재 구현 상태

현재 기본 `www` 화면은 Codex 실행 경로에 연결되어 있다. `www router`에는 별도의 다중 모델 실행 경로가 있다. 두 경로를 하나의 WWW 화면으로 통합하고 주 모델 선택, 선택적 교차검토, 전환 사유 표시를 연결하는 작업은 진행 중이다. 따라서 지금은 위의 다중 모델 동작을 기본 화면에서 모두 제공한다고 주장하지 않는다.

개발 환경에서는 Bun으로 `bun install` 후 `bun run start`를 실행한다. 현재 패키지는 `private`이며 공개 설치·배포 계약과 라이선스는 확정되지 않았다.

제품 목적과 구현 경계는 [제품 방향](docs/WWW_PRODUCT_DIRECTION.md), 기존 도구와의 관계는 [제품 경계](docs/OSS_POSITIONING.md)에 정리했다. 나머지 `docs/` 기록은 과거 설계와 내부 개발 자료이며 현재 제품 계약으로 해석하지 않는다.
