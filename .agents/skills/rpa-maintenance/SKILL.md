# RPA Maintenance

번호는 `05`, Skill ID는 `RPA-MAINT`다. [공통 Receipt 계약](../../../docs/workflows/RPA_RECEIPT_CONTRACT.md)을 사용한다.

1. 붙여 넣은 요청과 로그를 원본과 분리해 보존하고 자격증명·고객명·계좌·메일 원문을 정제한다.
2. 증상을 설정, 코드, 외부 시스템, 데이터 품질, 권한, 네트워크 또는 미분류로 나누고 영향 Process·Task·Unit과 revision을 찾는다.
3. 관찰 사실, 가설, 확인된 원인을 분리한다. 재현이나 코드 근거가 없으면 원인을 확정하지 않는다.
4. 확인된 Unit에만 최소 변경을 적용하고 직접 테스트, 연결된 회귀 테스트, 재실행 안전성을 검증한다.
5. 고객에게 전달할 설명과 운영자가 볼 기술 정보를 별도 Artifact로 만들고 `rpa-safety`에 넘긴다.

완료는 재현 조건, 확인 원인, 변경 Unit, 회귀 결과, 재실행 범위와 운영 복귀 조건이 같은 Receipt에 있는 상태다. 입력이 부족하면 필요한 추가 자료를 한 초점씩 질문한다.
